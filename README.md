I told my phone I needed some space, so it deleted my photos, cleared my cache, and started seeing other chargers. This program writes that one funny line to `/output/entry.txt` for the judge — the line itself is the whole entry, nothing more. It stays inside the gate: one sentence, 114 characters, with the twist saved for the very last words. The setup borrows the language of a breakup; the phone just follows the instruction to the letter.

## Run

```sh
python3 main.py
```
